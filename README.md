# Mishima oversized trailer / 低床１６輪

English | [日本語](README.ja.md)

**A 3.2 m-wide, 16-wheel lowbed for hauling heavy machinery across Project Japan.**

The Mishima 16-wheel lowbed for ETS2 1.60–1.61, with cargo fixes, more jobs and a centred rear plate mount. This is an unofficial update of MASAKICCI's trailer. It includes only the 3.2 m wide lowbed; the full Mishima trailer pack is not required.

[Download the mod](https://github.com/kubojion/ets2-mishima-oversized-trailer/releases/latest) · [Report a problem](https://github.com/kubojion/ets2-mishima-oversized-trailer/issues)

![Eight cargo options on the Mishima 16-wheel lowbed](https://github.com/user-attachments/assets/98db5471-f068-464d-9baa-a72fe80e322a)

## What changed

- Fixed missing cargo and the excavator's pink textures.
- Added six cargo choices, bringing the total to eight: excavator, asphalt mill, bulldozer, wheel loader, Volvo EC220E, Volvo L250H, Hitachi and Kobelco excavators.
- Added pickup and delivery support for 160 Project Japan company types, including those in Awaji and Ikata.
- Centred the rear plate mount, moved the holder against the trailer and brightened the sequential indicators.

## Requirements

ETS2 1.60–1.61, Project Japan, Heavy Cargo Pack and Volvo Construction Equipment DLC.

[Number Plate Reborn](https://gist.github.com/kuramochia/9d98537c51f1700f8e8e79b392733d87) is optional for its plate designs and is downloaded separately.

## Install

1. Download `mishima_lowbed_16w.scs` from the release's **Assets** list.
2. Copy it to `Documents/Euro Truck Simulator 2/mod`.
3. Enable **Mishima 16-Wheel Lowbed** in Mod Manager, above Project Japan and Number Plate Reborn if you use it.

Remove the old lowbed `.scs` file. Disable the old **Cargo and Companies** and **Centre Plate and Brighter Indicators** add-ons. If you use the full Mishima pack for its other trailers, keep it below this mod.

or a Reborn plate, choose the **Mishima 01** rear bumper and fit a rear plate to the centre slot.
