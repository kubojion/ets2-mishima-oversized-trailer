# Mishima oversized trailer / 低床１６輪

[English](README.md) | 日本語

**全幅3.2 mの低床16輪トレーラーで、Project Japan各地へ重機を運べます。**

MASAKICCI氏の「低床１６輪」をベースにした、ETS2 1.60–1.61対応の非公式改修版です。積荷の表示不具合を直し、運べる重機や仕事を受けられる会社を増やしました。リアのナンバープレート位置やウインカーの明るさも調整しています。

収録しているのは全幅3.2 mの低床トレーラー1台のみです。このMOD単体で使えるため、元のMishimaトレーラーパックを別途導入する必要はありません。

[ダウンロード](https://github.com/kubojion/ets2-mishima-oversized-trailer/releases/latest) · [不具合の報告](https://github.com/kubojion/ets2-mishima-oversized-trailer/issues)

![低床１６輪トレーラーに積載できる8種類の積荷](https://github.com/user-attachments/assets/98db5471-f068-464d-9baa-a72fe80e322a)

## 変更点

- 積荷が表示されない問題と、油圧ショベルのテクスチャがピンク色になる問題を修正しました。
- 積荷を6種類追加し、計8種類にしました。油圧ショベル、アスファルト切削機、ブルドーザー、ホイールローダー、Volvo EC220E、Volvo L250H、日立製ショベル、コベルコ製ショベルを運べます。
- 淡路・伊方を含むProject Japan各地で仕事が出るよう、160種類の会社に積荷の搬出・搬入設定を追加しました。
- リアのナンバープレートを中央に取り付けられるようにし、ホルダーが車体から浮いて見える隙間も調整しました。シーケンシャルウインカーは昼間でも見やすいように明るくしました。

## 必要なもの

ETS2 1.60–1.61のほか、Project Japan、Heavy Cargo Pack DLC、Volvo Construction Equipment DLCが必要です。

[Number Plate Reborn](https://gist.github.com/kuramochia/9d98537c51f1700f8e8e79b392733d87)のナンバープレートを使いたい場合は、そちらも別途導入してください。必須ではなく、本MODにも同梱していません。

## 導入方法

1. リリースページの **Assets** から `mishima_lowbed_16w.scs` をダウンロードします。
2. `Documents/Euro Truck Simulator 2/mod` にコピーします。
3. MODマネージャーで **Mishima 16-Wheel Lowbed** を有効にし、Project Japanより上に配置します。Number Plate Rebornを使う場合は、それよりも上に配置してください。

旧版から更新する場合は、古い低床トレーラーの `.scs` ファイルを削除し、旧アドオンの **Cargo and Companies** と **Centre Plate and Brighter Indicators** を無効にしてください。元のMishimaパックに入っているほかのトレーラーも使う場合は、パックを残したまま、本MODより下に配置してください。

Rebornのナンバープレートを後ろに付ける場合は、リアバンパーを **Mishima 01** にして、中央の取付スロットを選んでください。
